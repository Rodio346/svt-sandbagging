# Public data: text-free export of every evaluation run

`runs.csv` (one row per evaluation run) and `presentations.csv` (one row per answered question
presentation) are a **sanitized export** of the raw Inspect logs, written by
[`scripts/sanitize_logs.py`](../scripts/sanitize_logs.py). They are enough to reproduce every
number in [`RESULTS.md`](../RESULTS.md) and [`results/analysis/`](../results/analysis):

```bash
python scripts/analyze.py --data data --dataset wmdp --out results/analysis
```

## What is NOT in here

The raw logs are not published. This export contains **no benchmark content** and no free text:

- **no question text, no answer options, no answer key** for WMDP (or any protected dataset);
- **no original WMDP item ids** — items are renamed `wmdp-bio-item0042` etc. (order-preserving
  pseudonyms, so runs still pair item by item);
- **no option labels that map to the original dataset** — option indices (`chosen_choice`) are
  relabelled with a secret random permutation per item. Every detector only tests whether two
  answers are the *same* option, which this preserves, so results are unchanged;
- **no model outputs**: no completions, scratchpads, reasoning, thought summaries, or monitor
  explanations — only their lengths (`scratchpad_chars`, `reasoning_summary_chars`);
- **no request metadata**: no API keys, headers, request ids, run ids, file paths, hostnames,
  package lists or exact timestamps (run date only).

The sanitizer keeps only an allowlist of fields and refuses to write if the output contains any
question stem or option text (checked against the raw logs at export time), an original item id,
an API key value or key-like string, or any free-text cell.

The synthetic arithmetic pilot (`dataset = arith`) is not protected: its items are generated by
this repository's code.

## `runs.csv`

| column | meaning |
|---|---|
| `run_id` | `r001`… joins to `presentations.csv` |
| `phase` | `pilot`, `panel`, `main`, `main_x50`, `difficulty_panel` (honest runs of the independent panel in `configs/study.yaml` that only defines the floor set) |
| `requested_model` | model id as requested (map to pinned ids with `aliases` in `configs/study.yaml`) |
| `dataset`, `condition`, `arm` | pool, prompt condition, arm name (e.g. `calibrated_x50`; `stemless_main` = every stem removed on the main 300 items, `stemless` = the earlier 100-item draw) |
| `target_accuracy` | X for calibrated/coached arms |
| `threshold`, `n_items`, `n_perms`, `seed`, `replicate`, `arm_suffix`, `n_redacted` | task settings |
| `max_tokens`, `reasoning_effort`, `temperature` | generation settings |
| `status`, `n_samples`, `run_date`, `inspect_version` | run outcome and provenance |

## `presentations.csv`

| column | meaning |
|---|---|
| `run_id`, `item_id`, `source`, `perm_id` | which run, (pseudonymous) item, subset, option order |
| `redacted` | question stem was blanked (redacted / stemless control) |
| `intrinsic_difficulty` | arithmetic level (pilot only) |
| `correct`, `parse_failed` | answer correct; answer could not be parsed |
| `chosen_position`, `correct_position` | letter position chosen / of the correct option (0–3 = A–D) |
| `chosen_choice` | which option (relabelled per item for protected data) |
| `monitor` | scratchpad-monitor score 0–1 (blank if no monitor) |
| `input_tokens`, `output_tokens`, `reasoning_tokens` | token usage |
| `resolved_model`, `stop_reason` | version the provider served; why generation stopped |
| `scratchpad_chars`, `reasoning_summary_chars` | lengths only, no text |

WMDP is by Li et al. (2024), [cais/wmdp](https://huggingface.co/datasets/cais/wmdp); use the
original dataset for its content.
